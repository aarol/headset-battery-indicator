# What's changed

* Updated headsetcontrol to [4.2.0](https://github.com/Sapd/HeadsetControl/releases). This brings support for many new headsets.
* Added portable mode. In portable mode, the application does not touch the Windows registry or any other system files. Settings are stored in a file in the same directory as the executable, `headset-battery-indicator-settings.toml`.

**Full Changelog**: <https://github.com/aarol/headset-battery-indicator/compare/v3.6.0...v3.7.0>
