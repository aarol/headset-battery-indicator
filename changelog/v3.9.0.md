## What's Changed

* Added "Icon" submenu to the tray icon context menu. This allows you to change the tray icon between the image icon and the new and old text icons.
* Reworked the event loop handling to do the polling / tray icon logic on different threads. This greatly improves responsiveness of the menu
  * Because of this, it has been possible to increase the default headset polling rate from 1s to 2s. This should hopefully reduce the crackling caused by interference that some users have reported.
* Fixed a bug where when connecting a new headset, a notification with nonsensical values would be shown.

**Full Changelog**: https://github.com/aarol/headset-battery-indicator/compare/v3.7.0...v3.8.0
